# A 分支专用：需求访谈、内容与八套视觉探索

**仅在用户选择 A 之后执行；B 不执行八套预览或全稿确认。详见 [B 直接生图](image-fast-path.md)。**

## 输入约束
读取任务与已有素材，建立一个唯一 `project.json`。需要时一次性问：主题/受众/使用场景、演讲时间和页数、语言、16:9或其他比例、文字密度、图表与图片偏好、可否联网、源数据权限、交付格式、动画预期及软件版本。已有答案绝不重问。用户要求最简/竖版/纯图片的例外优先。

## 从内容提纲到图稿
每页设置：`intent`（单一表达目的）、`headline`（明确信息）、`evidence`（图片/图表/数据/引用）、`copy`（最终文字）、`layout_notes`（布局风险）、`assets`（来源和许可）。核对受版权保护素材的许可和引用；不直接搬用他人模板作为自有设计。中文或中英混排按真实行长预估换行。

## 八套风格卡
每套展示至少一个真实可见画面，普通稿每种风格**1 张代表页**（共 8 张），科研/竞赛/重大汇报每套**封面＋典型内容页**（共 16 张）；仅文字描述不得代替图像。可参考的差异维度：

| 编号 | 视觉方向示例 | 主要差异（不是只改色） |
|---|---|---|
| 01 | 水墨入海 | 留白、传统墨韵和现代资料块融合 |
| 02 | 黑银工业展 | 机械宏观摄影、金属边缘光、深色网格 |
| 03 | 大字编辑设计 | 排版主导，摄影切割，强文字层级 |
| 04 | 学术杂志 | 数据复合图、脚注系统、理性网格 |
| 05 | 自然叙事 | 大幅纪实摄影与细腻空间留白 |
| 06 | 轻量信息可视化 | 流程、卡片、图表与微符号 |
| 07 | 科技展馆 | 空间深度、线框界面和结构剖视 |
| 08 | 极简国际演讲 | 极少元素、强调结论与数值对比 |

以上是*可替换方向*；须按主题另行生成，避免固定套八种。每种具体给出主色、字体、构图、图片语言、信息密度及动画空间。用户可混搭，锁定 Design Spec 后所有批次复用同一规范。

## 复杂样页试装
风格选定后，从内容最多、主体最多、动效最难的页面中挑一张，试验：字体可落地、文字换行合理、背景去字干净、前景能独立移动、PPTX可打开、目标软件动画方法可实现。内部失败可重做样页，不需要用户多一个审批节点。

## 图稿审核 Gate
展示所有正式页的完整设计稿，顺序、准确文案、构图、图层视觉、引用可读。用户确认后保存原图/哈希/页序/版本为不可变基准；之后用同基准对照渲染，不擅自改变主题设计。

## v2.3 分级内容提纲与视觉连贯性

- 普通课堂与文艺推荐，逐页提纲由 AI 内部核对并可直接进入八套风格探索；科研、创新竞赛和复杂商业报告必须在继续设计前先由用户确认**详细逐页提纲**。
- 用户选定的风格锁定**核心视觉语言**（配色、字体、材质、图像质感与留白节奏），但**不锁死版式**。封面/章节/数据/图文/结尾可以完全不同构图；最终全套检查视觉连贯性。
- 内容事实按风险分级验证；关键数据、论文、实验图绝不能编造。AI 图像不得冒充真实实验照片或未经证实的证据。
- 重点文字、图表和 LOGO 位于适配画幅的安全区；满版摄影、纹理和装饰可出血。逐页核对真实字号、文本框、错字和裁切。
- 兼顾艺术字审美与许可：A 要核查可用字体及目标软件嵌入/回退，必要时将非普通装饰字做静态视觉元素，**普通文字仍需可编辑**；B 以最终图片清晰与正确为准。
- PILOT 复杂样页优先内部迭代，测试可落地即自动推进；若明显无法满足用户锁定的视觉或关键编辑/动效需求才提请用户裁定。
- ARTWORK 普通稿整套审核，大型复杂稿可逐批核准；最终**所有页面**审核完毕之前不得 REBUILD。
