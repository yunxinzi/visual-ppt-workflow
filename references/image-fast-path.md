# B 静态图片路线 v2.2：两预览 Gate + B1/B2 子分支

**B 分支不采用 A 的 8 套风格预览、复杂样页分层试装、完整图稿审批、原生 PPTX 重建和动画验证，但新增一对 B1/B2 的同页预览及用户确认 Gate。**

## 1. B 已选择，生成前先明确必要内容

记录 `workflow_branch="B"`、`mode="image"`、`brief.animation_requested=false`。如果主题、材料等尚无法确定一张代表性内容页，则先仅询问缺失的必要信息。其余未指定事项使用内容任务所需的最低配置（例如比例或页数）；不得暗中加“完美画质”“超写实”“电影级”“无噪点”“蓝紫科技”等词到 B1 的视觉提示词。

## 2. B1 与 B2 同页真实对照预览（必做，不能省略）

选一张具有代表性、能展示成品画质、文字与图文关系的 PPT 正式内容页。准备**同一条基础页面提示词**，包含该页相同的主题、真实文案、事实素材及用户明确限制。两张图使用**相同内容、尺寸、比例、生成模型、参考素材**（有 seed 功能可尽量用相同 seed），除下面新增条件外不改变视觉要求：

**B1 无内置视觉约束：** 只使用基础页面提示词，不添加任何额外的照片质感、颜色倾向、镜头、材质、光效、锐度、滤镜、噪点或其他审美要求；用户明确指定的要求仍应遵循。这里的“不施加约束”指**不增加 Skill 内置视觉约束**，不是忽略用户主题、真实内容、画幅与安全规则。

**B2 固定画质约束：** 将以下**完整原文**追加到**与 B1 完全相同**的基础提示词末尾，不自行改写、缩短或添加别的额外画质限定：

> 画面保持干净自然的真实照片质感：不要数字噪点与彩色噪点，不要颗粒覆盖，不要过度锐化，不要 HDR 与油腻高光，不要蜡质表面，不要脏灰色调，不要假细节与压缩伪影。

两次生图应产生**两张真实、完整、独立的 PPT 页面预览**，不得仅描述差别、复制一张、只修改滤镜、输出合成拼贴后冒充两张独立图片；可以并排展示独立图片。不要生成 8 套风格。图片预览需要完成基础 QA（文字可辨、无裁切、没有明显错误）；若工具缺失，明确阻碍，**不得以文字预览冒充已生图**。

## 3. 预览展示后的固定话术与停顿 Gate

在呈现 B1、B2 两张预览后，**必须紧接着显示**：

> 可选择仅开始 B1 分支或者仅开始 B2 分支，默认是同时开始 B1 和 B2 生成。

此时停止，不继续生成整套图片，直到收到用户答复。接受用户选择：`仅 B1`、`仅 B2`、`同时生成 B1 和 B2`；**当用户查看预览后只回复“确认”“按默认”“开始”时，按默认 `both`**。用户选 B 时并未许可提前用默认值生成完整两套；展示双预览之后才可进行确认。持久化 `b_generation_mode` 和 `gates.b_variant_confirmed=true`。

## 4. 确认后直接批量生图

制定整套逐页主题、证据与文案后，使用预览确定的基线模型、比例、参考内容生成页面；按最适合宿主工具的批次并行，必须每页为**独立完整高分辨率页面**，不是 12 页拼一张合成海报。

- 仅 B1：对每页使用用户原始任务与真实页面内容，不额外附加任何 Skill 内置视觉画质约束；交付一整套。
- 仅 B2：对每页使用同一基础任务提示词 + 上面逐字固定的画质约束；交付一整套。
- `both`（默认，经确认后）：**针对整套的每一页分别执行 B1 和 B2**，页数为 `slide_count × 2`；两套用独立文件夹 `B1/slide-01.png`、`B2/slide-01.png` 等保存，逐页内容可对照，不能交错、挪用或省略任意分支。

适当分批（通常 3–5 页/批），节省无效重复生成；按真实图片内容而非“生成完成”的模型文字判定成功。若宿主有生图调用配额，不能未经用户授权将默认双套偷换成单套。

## 5. 每套分别 QA 与交付

逐页检查内容完整、正确性、中文文本清晰、无黑屏/局部黑块、裁切、伪影、数值错误与画幅不一致，记录实际可验证的文件数量。B2 额外检查**是否确实在每页提示词使用固定原文**，不保证模型一定遵守每项负面约束；B1 只核查未被程序自动追加该约束。视觉比较不能把 B2 质量优越当成默认事实。

默认产物是选定分支的完整 PNG/JPG 图片集；`both` 须交付 B1、B2 两份可清晰区分的文件集。用户要求时可再将各版本的整页图片分别封装为**纯图片版 PPTX/PDF**，注明不可逐项编辑且不含动画；不恢复 A 的对象分层。保存版本与生成记录并核实实际文件路径，勿伪造下载链接。

## 6. 断点续作

`b_preview`：只制作两张代表页预览；`b_await_confirmation`：两图齐备，等用户确认；`image_generate`：已选子分支，生成所有对应整套页；`image_qa`：独立核验；`image_delivered`：交付选定的一个或两个版本。不可把初次选 B 理解成已确认第二级子分支。已有此前版本的 B 项目如果已经生成，不回溯强制补作新预览。
