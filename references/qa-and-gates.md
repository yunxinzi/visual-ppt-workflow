> **分支范围：** 本文原有的 8 套风格、样页试装、图稿锁定、编辑性和动画 Gate **只适用于 A 分支**。B 需先通过**同一代表页 B1/B2 两张真实预览及用户确认 Gate**，再执行 [双版本图片 QA](image-fast-path.md#5-每套分别-qa-与交付)，不得因未完成 A 的八套预览或分层重建而判失败。

# 验收标准（Gate Policy）

| 门槛 | 最低证据 | 不合格处理 |
|---|---|---|
| 需求 | `project.json` + 逐页主题/关键事实 | 补齐影响正确性的要点 |
| 视觉探索 | 8套可见图与选版记录（除用户明确豁免） | 补足构图多样性 |
| 试装 | 复杂样页的渲染+主体移走检验（需可编辑时） | 先修技术路线再批量 |
| 图稿锁定 | 全套参考图+确认标记+文案版本 | 未确认不得批量正式构建 |
| 静态 | 所有最终页面渲染，参考图对照，无严重错漏 | 页级局部修复 |
| 编辑 | 原生文字/形状与独立前景抽查 | 修正分层或披露图片限制 |
| 动画（按需） | 对象/触发/过程/终态一致 | 调整动作或标注未实现 |
| 实播（条件允许） | 目标软件实际打开并留测试记录 | 未测需明确说明 |
| 交付 | 同一 `build_id` 的所有文件、实存校验 | 重新生成不一致文件 |

## 静态检查
逐页比对用户锁定图稿及对应渲染: 信息完整、事实可核查、文字与行宽可读、图片不畸变、对齐/裁切合理、无遮挡、无黑屏/空白/半页黑色、全套有节奏变化。检查页序和图稿ID关联。允许使用MAE/SSIM/热图发现差异，但不可用单独阈值宣称审美合格。对比需同尺寸、同颜色空间，不随意拉伸。图稿与交付版本相同。

## 故障优先级
- `BLOCKER`: 文件损坏、空白页、整图伪分层、内容虚假、目标软件无法播放关键内容；阻止交付。
- `MAJOR`: 文字溢出、主体残影、流程错误、重要图表数据不一致、动画错误；修复或明确披露后才可交付。
- `MINOR`: 微小字距、边框装饰等；评估代价后局部调整。

## 检测能力诚实分层
`structural` = ZIP/XML结构检查；`rendered` = 本环境渲染；`editable_test` = 真实修改对象；`target_playback` = 目标PowerPoint/WPS中实播。不可推断高层测试由低层测试自动完成。

## 循环策略
构建过程中及时验收；最后检查每一页。用户指定固定3轮则每轮记录具体缺陷和变化；未指定的项目禁止无根据重复3次。同类问题两次无改善先定位根因或换工具。无阻断缺陷时立即停止重做。

## B 专用检查项（v2.2）

1. 未生成两张独立预览时，不能请求第二次确认或开始批量生产；检查两图对应同一正式内容页，除固定约束外其他任务提示词保持一致。
2. 预览后显示固定一句：“可选择仅开始 B1 分支或者仅开始 B2 分支，默认是同时开始 B1 和 B2 生成。”**等待用户明确确认**；“默认”不是自动启动的授权。
3. B1 不得由 Skill 自动加入照片感/HDR/无噪点等任何画面质量修辞；B2 的每页提示词必须包含原始固定约束全文。
4. 仅 B1 或仅 B2 → 每页 1 张正式图片；`both` → 每页 B1/B2 各 1 张。独立目录、独立审图、独立文件数量与导出检查。
5. 缺页、同一图片冒充两种结果、借用缩略拼贴切割、用户未确认就开始生成，均视为 BLOCKER。
